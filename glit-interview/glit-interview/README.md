# Glit — 삶이 섬이다

길거리 오프라인 인터뷰이 모집용 프레젠테이션 페이지. 모바일/태블릿에서 손에 들고 넘기며 보여주는 용도.

## 구조

- `index.html` — 7개 화면 (표지 → 참교육 → 리센느 → 질문 → 섬 → 팀·리센느 스토리 → 제안)
- `style.css` — 크림/코랄 에디토리얼 톤, 세로 스냅 스크롤
- `main.js` — 진입 애니메이션, 진행바, 하단 인디케이터, 키보드(←/→) 이동

## 테마

기존 [glit-in.netlify.app](https://glit-in.netlify.app/)의 브랜드 토큰을 그대로 가져왔습니다.

| 토큰 | 값 | 용도 |
|---|---|---|
| `--coral` | `#D9774E` | 포인트 (STEP 라벨, 강조어) |
| `--ink` | `#2E2B28` | 본문 |
| `--ivory` | `#F4ECDD` | 카드 배경 |
| `--cream` | `#FFFAF1` | 기본 배경 |

폰트도 동일하게 **Pretendard Variable**(본문) + **Gowun Batang**(제목·시).

표지는 주신 포스터를 참고해 석양 그라데이션 + 섬 위에 홀로 선 사람을 인라인 SVG로 그렸습니다. 이미지 파일이 아니라 코드라서 어떤 화면에서도 안 깨집니다.

## 화면 구성

| # | 화면 | 내용 |
|---|---|---|
| 0 | 표지 | 석양 + 섬 (인라인 SVG) |
| 1 | 참교육 | `참교육.jpg` 크게 + "혹시 이 작품 아시나요?" |
| 2 | 리센느 | `리센느.jpg` → **탭하면 "거제 야호! 리센느" 정답 공개** |
| 3 | 질문 | "최근에 가장 인상 깊었던 글귀나 문장이 있으세요?" |
| 4 | 섬 | `섬.jpg` 단독 (시가 이미지에 있어 멘트 없음) |
| 5 | 팀 소개 | 글릿 + 리센느 스토리 카드 |
| 6 | 제안 | 인터뷰 제안 + QR |

리센느 화면은 **다시 탭하면 원래대로 돌아옵니다.** 다음 사람에게 그대로 재사용하면 됩니다.

## 아직 남은 placeholder

STEP 06의 인스타 QR (`.sns__qr`) 하나뿐입니다. 이미지 넣으실 때:

```html
<img src="./images/qr.png" alt="인스타그램 QR" />
```

## 로컬 확인

```bash
npx serve .
```

## 배포

Netlify에 정적 배포. `netlify.toml`의 `publish = "."` 그대로 사용.

```bash
npx netlify-cli deploy --prod
```
